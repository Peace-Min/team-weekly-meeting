# 팀 주간보고

사내 근태관리의 주간보고를 팀 회의에 사용할 수 있도록 준비하는 별도 Windows 프로그램입니다.
로그인한 사내 웹페이지의 주간보고 조직 메뉴에서 조직명과 사용자 ID·이름·직급을 읽습니다. 보고서 탐색에는 기존 Netcus 모듈을 재사용합니다.
DB 접속이나 캘린더 설치 없이 빌드·실행할 수 있습니다.

## 사용

1. `TeamWeeklyMeeting.exe`를 실행하면 로그인 전용 창이 열립니다. 본인 사내 계정으로 로그인하면 창이 닫히고, 로그인한 계정을 기준으로 조직도와 구성원을 자동으로 불러옵니다. 별도 로그인·조직도 새로고침 버튼은 없습니다.
2. **팀**을 선택합니다. 본인 팀이 기본 선택되며, 선택한 팀과 하위 조직의 구성원이 조직도로 표시됩니다.
3. 조직도의 체크박스로 **오늘 참석자**만 체크하고 **참석자 보고서 준비**를 누릅니다. 전체 체크·해제도 가능합니다.
4. 발표자 이름이나 **이전 / 다음**으로 전환합니다. 각자의 스크롤 위치가 유지됩니다.
5. 보고서는 **기존 사이트의 주간보고 제목과 본문 영역만** 표시합니다. 사내 사이트의 좌측 메뉴·상단·좌우 장식은 제외합니다. **배율**에 25~500%를 직접 입력하고 **증감**에 1~475%를 입력한 뒤 **적용** 또는 Enter를 누릅니다. **축소 / 확대**는 지정한 증감 폭을 사용하고, **100%**는 기본 배율로 돌아갑니다.
6. **개별 창으로 열기**로 분리할 수 있습니다. 개별 창을 닫으면 원래 화면으로 돌아옵니다.
7. **보고 시작**을 누르면 보고서만 전체 화면에 표시됩니다. 설정 화면과 창 테두리는 보이지 않습니다.

보고 모드에서는 ←/↑/PageUp이 이전 발표자, →/↓/PageDown이 다음 발표자입니다. Home/End는 첫 번째/마지막 발표자로 이동합니다. 마우스 왼쪽 드래그와 휠로 본문을 스크롤하고, **Esc**로 보고 모드를 종료합니다. 발표자마다 스크롤 위치를 유지합니다.
보고 모드에서는 사이트의 편집 버튼을 숨기고 클릭 실행을 막습니다. 종료하면 원래 화면과 사이트 조작을 복원합니다. 보고서가 없거나 준비에 실패한 사람은 그 사람의 상태만 표시합니다.

발표 화면 하단의 도구막대에서 **이동(M) / 펜(D) / 형광펜(H) / 지우개(E)**를 고릅니다. 이동은 기존 드래그 스크롤이며, 나머지 모드는 마우스로 그리거나 획을 지웁니다. 색상·굵기 선택, **되돌리기(Ctrl+Z, 최대 30회)**와 **전체 지우기**, 도구막대 접기를 지원합니다. 휠 스크롤과 발표자 이동 키는 그리기 모드에서도 사용할 수 있습니다.
그림은 발표자별로 구분되며 보고서와 함께 스크롤됩니다. 발표를 종료했다가 다시 시작해도 해당 보고서를 새로 읽기 전까지 유지됩니다. **보고서 새로고침이나 앱 종료 시 사라지는 임시 메모이며 서버의 보고서에는 저장하지 않습니다.** 보고 시작 전에 배율을 맞추세요. 발표 중에는 Ctrl+휠 등으로 실수로 배율이 바뀌는 동작을 막고, 종료 시 복원합니다.

본문의 원래 HTML 표·색상·글꼴·링크를 유지하고 바깥 메뉴와 장식만 숨깁니다. 원본의 600px·560px 고정 폭은 뷰어 너비에 맞추며, 창 크기를 바꾸면 함께 조절됩니다. 별도 본문 디자인을 만들지 않습니다.
상단 ‘주간보고’ 제목 바는 원본 이미지 대신 HTML·CSS로 표시해 확대해도 글자가 선명하며 가로로 늘어나지 않습니다.
최신 보고서는 개인 목록의 맨 위 글입니다. 표시된 보고 기간으로 지난주 글인지 확인하세요.
팀 선택은 다음 실행에도 유지합니다. 참석자 체크는 같은 날짜에만 복원하고, 다음 날에는 다시 체크합니다. 조직도와 발표 순서는 상위 조직의 직속 인력을 먼저 표시하고 하위 조직을 이어서 표시합니다. 같은 조직 안에서는 기존 명부 순서를 유지합니다.
보고서가 없거나 접근이 실패하면 상태를 표시합니다. 세션이 만료되면 로그인 창이 다시 열리고, 인증 후 조직도를 갱신하므로 참석자를 확인한 뒤 다시 준비합니다.
일반 화면에서는 사이트의 수정·삭제 기능도 원래대로 동작합니다. 자동 준비 자체는 조회만 수행합니다.

## 연결 및 저장

조직도와 구성원 정보는 로그인한 페이지의 주간보고 메뉴(`#submenu1`)에서 가져옵니다. 화면의 조직 제목·사용자 링크·표시 순서·본부와 하위 팀 구분을 사용하며 DB에는 접속하지 않습니다. 페이지 메뉴를 읽지 못하면 명부를 표시하지 않고 오류를 알립니다.
현재 로그인 창에서 인증한 사내 계정 ID를 조직도 조회에 사용합니다. 다른 앱의 저장된 로그인 계정으로 대신 조회하지 않습니다.
비밀번호를 따로 수집하거나 저장하지 않습니다. 로그인 쿠키는 `%APPDATA%\TeamWeeklyMeeting\WebView2`에 기존 캘린더와 분리해 보관합니다.
계정별 설정 관리는 사용하지 않습니다. 팀·당일 참석자·배율·증감 폭·창 크기 및 최대화 여부를 `%APPDATA%\TeamWeeklyMeeting\meeting.json`에 공용으로 저장합니다. 로그인 계정이 바뀌어도 같은 로컬 설정을 사용하며, 설정 파일에는 로그인 계정 ID를 저장하지 않습니다. 참석자 체크는 같은 날짜에만 복원합니다.
기존 공용 파일이 없을 때만 이전 설정 중 가장 최근 파일을 한 번 가져옵니다. 이후에는 계정별 파일을 만들거나 갱신하지 않습니다. 배율·증감 폭과 참석자·팀 변경은 즉시 저장하며, 창 크기는 설정 저장 시점과 종료 시 저장합니다.

## 회사 디자인과 문의

제공받은 회사 로고 PDF(`Assets/company-logo-source.pdf`)에 포함된 이미지를 추출해 사용하며, NET 심볼을 앱 아이콘으로 사용합니다. 흰색 헤더와 주황색 주요 버튼은 앱 셸에만 적용하며, 사내 보고서 본문 디자인은 유지합니다.
아이콘은 `tools/build-meeting-icon.ps1`로 추출한 원본 이미지에서 다시 만들 수 있습니다. PDF 안의 이미지는 374×97px이며, 로고를 임의로 다시 그리거나 글자를 대체하지 않습니다.
Windows 아이콘은 흰 배경을 투명 처리하고 추가 여백 없이 원본 심볼을 최대 크기로 배치합니다. 앱 헤더의 흰색 배경은 유지합니다.
상단 우측 **문의 및 버그제보**에서 기존 캘린더와 같은 `phmin@netcus.com` / 랜메신저 **민평화**를 안내합니다. 메일 주소 복사·로그 경로 복사·로그 폴더 열기를 제공합니다.
상단 **버전 정보**에서 현재 버전의 짧은 변경 요약을 확인하고, 이전 버전은 펼쳐서 읽습니다. NETCUS 심볼에 문서 표시를 더한 전용 아이콘으로 다른 사내 앱과 구분합니다.

로그는 `%APPDATA%\TeamWeeklyMeeting\logs\meeting.log`에 남습니다. 파일은 약 5 MiB마다 회전하며 최신 파일 포함 5개를 보관합니다. 사용자 동작·선택·페이지 이동·오류·소요 시간과 실행 환경을 기록하며, 비밀번호·쿠키·보고서 본문은 기록하지 않습니다.
디버깅 절차와 이벤트 설명은 [DIAGNOSTICS.md](DIAGNOSTICS.md)를 참고하세요.

## 빌드 / 실행

개발 실행에는 .NET 9 Desktop Runtime과 Microsoft Edge WebView2 Runtime이 필요합니다. 배포 설치기는 .NET 런타임과 오프라인 WebView2 설치기를 포함합니다.

```powershell
dotnet build meeting/TeamWeeklyMeeting.csproj -c Release
dotnet run --project meeting/TeamWeeklyMeeting.csproj
dotnet publish meeting/TeamWeeklyMeeting.csproj -c Release -r win-x64 -o publish/win-x64 --self-contained true
```

위 publish 명령은 Inno Setup을 자동 실행하여 `dist/installer/`에 설치 패키지까지 생성합니다. 생성한 설치 EXE를 폐쇄망에 반입해 사용합니다. 수동 publish 폴더를 옮길 경우 폴더 전체를 복사합니다.

## 자동 QA

```powershell
dotnet run --project meeting/TeamWeeklyMeeting.csproj -- --smoke-test
Get-Content "$env:TEMP/TeamWeeklyMeeting-smoke-result.txt"
```

실제 WebView2와 합성 조직도·로그인·보고서를 사용합니다. 모든 브라우저 요청은 로컬 응답으로 대체하며 사내 사이트나 DB에 접속하지 않습니다.
팀 및 하위 조직, 체크박스, 팀 전환, 당일 참석 복원, 쿠키 공유, 최상단 보고서 선택, 원본 본문 HTML·표·색상 유지, 메뉴·장식 제외, 로그인 창과 조직도 자동 갱신, 25~500% 네이티브 확대·축소, 증감 폭 직접 입력과 검증, 공용 설정·창 크기 복원 및 계정별 설정 기능 제거, 전체 화면 보고 모드, 실제 브라우저 키 입력·마우스 드래그·휠·Esc, 스크롤 유지, 창 분리·복귀, 예외 처리, 회사 로고·아이콘, 상위 조직 인력 우선 정렬, 문의 연락처·로그 경로와 동작·오류 로그를 검증합니다.
실제 사내 계정 로그인과 현재 사이트 구조의 최종 확인은 사내망에서 수행해야 합니다.
