# 보고서 하단 발표자 이동 기획

상태: 2026-11-09 시안 승인, 구현 진행.

발표할 때 마우스를 다음 사람에게 건넨다. 키보드 없이 보고서 끝에서 바로 다음 사람 화면을 열 수 있어야 한다.

- 사용자가 선택한 4번 시안을 적용한다. 본문 끝 가운데에 같은 폭의 이전, 다음 버튼을 두고, 굵은 제목 아래 사이트 조직 메뉴의 표시 문구를 그대로 붙인다.
- 이동할 수 없는 쪽은 문구 없이 숨기고 자리는 유지한다. 보고서가 없거나 열리지 않는 사람도 현재 순서를 유지하고, 안내 아래에서 이전과 다음을 쓸 수 있게 한다.
- 별도의 끝으로 이동 버튼과 고정 이동 메뉴를 두지 않는다. 기존 키보드, 휠, 드래그와 필기를 유지한다. 보고서는 다시 읽지 않고 기존 뷰로 돌아가 스크롤과 필기를 복원한다.
- 사이트 메뉴 표시 문구를 이름과 직급으로 나누기 전에 보관한다. 브라우저의 보고서 영역과 WPF의 미작성 안내에 같은 발표자 선택 흐름을 연결한다.
- QA: 본문 끝에만 표시, 실제 마우스 클릭, 첫째와 마지막, 미작성, 확대와 필기 도구 겹침, 기존 단축키, 전환 뒤 포커스와 스크롤 및 필기 보존.
