# 자동로그인

## 처음 설정

1. 앱의 로그인창에서 본인 사내 계정을 입력합니다.
2. 개인 PC에서만 하단의 ‘자동로그인’을 체크합니다. 최초 상태는 해제되어 있습니다.
3. 로그인이 성공하면 인증정보를 저장합니다. 실패한 입력은 저장하지 않습니다.
4. 다음 실행부터 본인의 유효한 세션을 재사용하고, 만료됐다면 저장 정보로 로그인합니다. 조직도는 로그인한 웹페이지에서 다시 읽습니다.

같은 Windows 계정을 여러 사람이 공유하는 PC, 회의실 PC에서는 체크하지 마세요. 화면의 경고는 ‘공용 PC에서는 체크하지 마세요. 다음 실행부터 이 계정으로 자동 로그인됩니다.’입니다.

## 자동로그인 제한과 해제

- 자동 시도는 앱 실행당 최대 1회입니다. 세션 확인과 웹 인증 흐름은 합계 20초로 제한합니다.
- 실패하면 자동 반복하지 않고 수동 로그인창을 엽니다. 비밀번호 변경 후에는 올바른 비밀번호로 직접 로그인해야 저장 정보가 갱신됩니다.
- 수동 로그인창에 저장 설정이 남아 있으면 체크되어 표시됩니다. 체크를 해제하면 즉시 저장 정보를 삭제합니다.
- 자동로그인이 정상으로 바로 진입했다면 상단의 ‘로그아웃’을 누르면 저장 정보도 함께 삭제됩니다.

## 로그아웃과 계정 변경

상단에는 현재 계정 ID와 ‘로그아웃’이 표시됩니다. 로그아웃하면 저장 인증정보와 앱 전용 브라우저의 쿠키·사이트 저장소를 삭제하고, 조직도·참석자·준비된 보고서를 닫은 뒤 수동 로그인창으로 돌아갑니다. 해당 창을 닫아도 이전 계정 화면이 남지 않으며 상단 ‘로그인’으로 다시 시작할 수 있습니다.

다른 계정으로 로그인하면 그 계정의 페이지에서 조직도를 읽고 참석자를 새로 선택합니다. 보기 배율·증감 폭·창 크기는 공통 설정으로 유지합니다. 정상 자동로그인에서는 같은 날짜의 참석자 설정을 복원할 수 있지만 수동 재인증·로그아웃·계정 전환에서는 이전 참석자를 초기화합니다.

앱 전용 세션을 지우는 동작이며, 일반 Chrome이나 다른 사내 앱의 로그인은 건드리지 않습니다. 확인되지 않은 서버 로그아웃 주소를 임의로 호출하지 않습니다.

정식 v1.0.0에서는 로그아웃·수동 로그인 시 다운로드한 이미지·스크립트·글꼴 캐시는 유지합니다. 쿠키와 사이트 로컬 저장소는 삭제하므로 이전 계정의 인증 상태를 재사용하지 않습니다. 캘린더 앱처럼 파일만으로 첫 화면 신원을 복원하는 방식과 달리, 주간보고 앱은 실제 웹 세션을 확인하고 최신 조직 메뉴를 읽습니다.

## 저장 위치와 보호

- 인증정보: `%APPDATA%\TeamWeeklyMeeting\autologin.dat`
- 공통 화면 설정: `%APPDATA%\TeamWeeklyMeeting\meeting.json`
- 앱 브라우저 프로필: `%APPDATA%\TeamWeeklyMeeting\WebView2`

계정과 비밀번호 전체를 Windows DPAPI `CurrentUser`로 암호화합니다. 평문 config나 실행 폴더에 비밀번호를 넣지 않으며 직접 편집할 필요가 없습니다. 사이트의 기존 RSA 로그인 함수를 그대로 사용합니다. WebView2의 별도 비밀번호 저장/자동 완성은 꺼져 있습니다.

암호화는 Windows 사용자 계정에 연결됩니다. 같은 Windows 계정을 공유하는 환경까지 보호하는 기능은 아닙니다. 인증 파일이나 브라우저 프로필을 다른 사람에게 전달하지 마세요. 문의할 때도 인증 파일은 제외하고 진단 로그만 전달하세요.

설치·제거는 기존 사용자 데이터를 보존합니다. 제거 후 인증정보도 남기고 싶지 않다면 먼저 로그아웃하세요. 삭제 권한 오류가 발생하면 앱은 성공한 것으로 표시하지 않고 다음 실행에 자동로그인이 남을 수 있음을 안내합니다.

기술 근거: [Microsoft DPAPI](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection), [WebView2 브라우징 데이터 삭제](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2profile.clearbrowsingdataasync).
